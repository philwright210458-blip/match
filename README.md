# Fill Right

A simple browser game prototype for desktop and mobile.

## Run in VS Code

1. Open the `memory-match-game` folder in VS Code.
2. Install the **Live Server** extension if you do not already have it.
3. Right-click `index.html` and choose **Open with Live Server**.
4. For iPhone testing, open the Live Server URL using your PC local IP address.

Example:

http://192.168.1.24:5500/index.html
